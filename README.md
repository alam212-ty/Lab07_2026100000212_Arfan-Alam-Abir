This repository was created on 8 September 2026 for CSE 1102 Section 9 in order to learn and practice GitHub, Markdown, version control, and GitHub Pages.
Version Control is a system that tracks changes in files and manages different versions of a project.
Git is a distributed version control system used to track and manage code changes.
GitHub is an online platform for storing, sharing, and collaborating on Git repositories.
Git Bash is a command-line tool used to run Git and Unix commands on Windows.
The main parts of GitHub are Repository, Branch, Commit, Pull Request, Issues, and Actions.
The stages of Git/GitHub are Working Directory → Staging Area → Local Repository → Remote Repository
